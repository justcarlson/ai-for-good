# AI for Good

Small, playful AI demos for a hands-on workshop.

This repository will hold a presentation home page, runnable demos, reusable
prompts, and notes that explain how each demo was made.

## Planned demos

- **A little help grows:** a code-drawn motion story built with Claude Opus 5.5.
- **Make it clearer:** turn a fictional community notice into clear next steps.
- **From sketch to screen:** compare a short video prompt with its generated clip.

The first delivery is a review plan. Demo implementation and publication status
will be recorded here as they are verified.

## Working rules

Use separate Git worktrees for independent contributions. Record the exact model
and prompt for generated work. Keep credentials and private plans outside Git.
Use synthetic examples that contain no workplace or personal information.

OpenAI work uses ChatGPT subscription authentication. Paid model calls must stay
within the owner's task and monthly limits. Never expose model API keys to a browser.
