      3. What gives?

      Name one task to delay, shrink or ask for help on. Add a reason and a question for a person. This note does not change the hours above.

      Choose a task, add a reason and write one question.

      Run this activity

      Presenter · 5 minutes

      1. Start with must-do tasks and explain which deadlines you protect.
      2. Add too many hours to a day to show the warning. Choose what gives.
      3. Load the prepared suggestion and read its assumptions.

      Pairs · 15 minutes

      1. Place the musts, then the helps-others tasks.
      2. Choose what gives. Write the reason and a question to ask.
      3. Swap plans with a neighbor. Find one assumption in their plan.

      No devices: Print the task list and empty grid. Cross off hours and mark overflow. Vote by hands on what to delay.

      Debrief: What did you protect first and why? What would you ask a real colleague? Where could an assistant help, and where must a person decide?

      Check your plan: All musts placed, one named tradeoff and one question for a person.

      Prompt to reuse

      Place the tasks so every “must” meets its deadline. Name one task to delay, shrink or hand off, and write one question you would ask someone before deciding.
